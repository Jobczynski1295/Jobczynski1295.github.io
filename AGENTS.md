# Project
Personal About-Me website built with React and Vite.

# Commands
- npm install
- npm run dev
- npm run build

# Rules
- Store personal content in src/profile.js.
- Never invent facts about me.
- Use plain React and CSS.
- Make the website mobile-friendly and accessible.
- Never commit passwords, secrets, node_modules, or dist.

# Git Workflow
- Show and explain Git commands before running them.
- Use small commits with clear messages.
- Never force-push or rewrite Git history.
